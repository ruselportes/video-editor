# Local AI TikTok Affiliate Video Pipeline (CrewAI Version)

This document outlines the architecture for a 100% local, free-to-run AI video generator. To make it user-friendly, we use a **Frontend Dashboard**, and to make the AI smart, we use a **CrewAI Multi-Agent System**.

## The 3-Part Architecture (All within `video-editor`)

Per project rules, **EVERYTHING** lives inside the `video-editor` folder.

1.  **UI Dashboard (React/Vite):** A simple webpage where you upload your raw product video and hit "Generate TikTok." It embeds the Remotion player so you can watch the result before downloading.
2.  **AI Backend (FastAPI + CrewAI):** The brain. It receives the video, chops it, and spins up a "Crew" of AI Agents (Visionary, Marketer, Director) that talk to each other to build the perfect video.
3.  **Video Engine (Remotion):** The renderer. It takes the JSON Blueprint generated by the Crew and perfectly layers the video, audio, and dynamic captions.

## 2. The Python Backend (FastAPI + CrewAI)

Instead of one massive AI prompt, the backend spins up a company of AI workers using CrewAI and LangChain (talking to local Ollama).

```python
from fastapi import FastAPI, UploadFile, BackgroundTasks
from crewai import Agent, Task, Crew
from langchain_community.llms import Ollama
import os, json
from modules import scene_chopper, voice_generator, aligner

app = FastAPI()
job_status = {"status": "idle", "progress": 0, "message": ""}
local_llm = Ollama(model="llama3")

def run_multi_agent_pipeline(file_path: str, product_name: str):
    global job_status
    
    job_status = {"status": "processing", "progress": 10, "message": "Chopping raw video..."}
    clips = scene_chopper.detect_and_split(file_path, output_dir="./data/clips")
    
    job_status = {"status": "processing", "progress": 30, "message": "CrewAI Assembling..."}
    
    # 1. Define the Agents
    marketer = Agent(
        role='Viral TikTok Copywriter',
        goal='Write a highly engaging script for an affiliate product.',
        backstory='You are a master of TikTok psychology and hook-retention.',
        llm=local_llm
    )
    director = Agent(
        role='Video Editor',
        goal='Map video clips to the script and output JSON.',
        backstory='You are an expert at pacing and matching visuals to audio.',
        llm=local_llm
    )
    
    # 2. Define the Tasks
    write_script_task = Task(
        description=f'Write a 30-second script for {product_name}.',
        agent=marketer,
        expected_output="A 30-second conversational script."
    )
    build_json_task = Task(
        description='Take the script, map it to the provided video clips, and output the JSON Edit Blueprint.',
        agent=director,
        expected_output="A strict JSON object containing the Edit Blueprint."
    )
    
    # 3. Kickoff the Crew
    video_crew = Crew(agents=[marketer, director], tasks=[write_script_task, build_json_task])
    json_result = video_crew.kickoff()
    
    job_status = {"status": "processing", "progress": 70, "message": "Generating AI Voiceover..."}
    # Parse the script from JSON and generate voice
    script_text = json.loads(json_result)["voiceover_text"]
    audio_path = voice_generator.text_to_speech(script_text, output_dir="./data/audio")
    
    job_status = {"status": "processing", "progress": 85, "message": "Syncing captions..."}
    word_timestamps = aligner.get_word_timestamps(audio_path)
    
    # Combine final JSON
    final_blueprint = json.loads(json_result)
    final_blueprint["audio_track"] = audio_path
    final_blueprint["dynamic_captions"] = word_timestamps
    
    with open(f"../ui-dashboard/public/{product_name}_blueprint.json", 'w') as f:
        json.dump(final_blueprint, f)
        
    job_status = {"status": "complete", "progress": 100, "message": "Ready to preview!"}

@app.post("/api/generate")
async def generate_video(product_name: str, file: UploadFile, background_tasks: BackgroundTasks):
    file_path = f"./data/raw/{file.filename}"
    with open(file_path, "wb") as buffer:
        buffer.write(await file.read())
    background_tasks.add_task(run_multi_agent_pipeline, file_path, product_name)
    return {"message": "Job started!"}

@app.get("/api/status")
async def get_status():
    return job_status
```
